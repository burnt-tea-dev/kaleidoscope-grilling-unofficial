# A2.8.154 source candidate

Adapt the owned public host API to clean Cookery 1.6.2 while retaining G151–153
skewer, eating, rack, crop, pepper, guide and oil-brush repairs. The public
family API is now 0.2.13 and the guide transfer identity is 0.3.65.

Newly placed filled oil pots initialize their captured, position-bound quantity
before the author callback reads it. Unidentified legacy oil still fails closed;
the adapter never guesses a full pot. Seven powder recipes now pass all three
native millstone input gates in the public adapter, retaining author timing,
capacity and built-in recipe priority without requiring private server code.

Actual clean-author module tests cover the placement ordering failure and all
seven powders through hand, worker-container and dropped-item inputs. The author
1.6.2 cache already coalesces recipe registrations; no old lazy-return patch is
applied. This does not establish fixed callback time, TPS or a cure for host OOM.

The public local assembly profile uses an owner's legally acquired clean author
archive and the existing canonical family assembler. Complete third-party packs
are not published as this project's release assets. Existing same-version author
installations require the documented clean-install/cache acceptance procedure;
an owned pack version alone does not refresh altered author resources.

Source CI, complete-family BDS/saved-world validation and rendered-client
acceptance are separate. This source candidate does not claim full Java parity,
all visual effects or a completed from-zero human survival playthrough.
`client=false`, `production_ready=false`, `pending_client_acceptance`.
