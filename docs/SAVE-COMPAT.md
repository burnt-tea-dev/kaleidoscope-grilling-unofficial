# 存檔變更

2026-11-04 擁有者明確移除存檔相容鎖。`save_compat.py`、鎖清單、退役登記及其 required CI 已退役；不再要求只增不減、固定等待期或逐 ID 收據。

移除鎖不等於要求刪除玩家資料。修改有保存內容的功能時，只對受影響資料做一個可觀察的讀取、寫入與重啟測試；實際需要遷移才實作遷移，不預先增加框架。部署使用一份最新完整世界備份，更新成功後退役舊副本。

物品和工作站的當前實作是權威來源。需要查世界裡有哪些舊資料時，手動使用 `tools/ops/world_ids.py`；它預設由 `runtime_inventory.py` 收集當前來源，也可用 `--catalog` 指定清單。它只讀副本，沒有存檔鎖或自動阻擋。

真人操作不再是必要驗收。使用真實實作的測試、必要的引擎保存驗證與資源引用檢查；未觀察到的畫面不冒稱通過，也不因此擱置修復。
